# Public Services Across Victoria

Interactive visualisation of Victorian council spending, waste, libraries, public toilet locations and satisfaction.

## Run locally
Open this folder in VS Code and start Live Server on index.html.



## Included
- index.html, styles.css and app.js
- Eleven chart JSON specifications
- Only the processed CSV and map files referenced by those charts
- SVG decoration asset

Original spreadsheets, assignment documents, preview screenshots and preparation scripts are not needed to run the website.
